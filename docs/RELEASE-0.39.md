Video playback is now inside the Blades executable. Choose the exact file under
Media > Video; manage folders under Video Marketplace. A pauses/resumes,
Left/Right seeks ten seconds, X changes fit/stretch and B returns to the same
file list. No player adapter or Players folder is used. Old 0.38 Players files
can be removed manually after updating; saved scan paths/FTP settings are kept.

All 22 host suites, sanitizer checks, Xbox build/integrity checks and source
rebuild passed. The walkthrough includes actual host sample decoding with the
Blades renderer. This new embedded Xbox playback remains hardware-unverified.
Try the included 640x360 tests/media/sample.wmv and sample.mp4 from the source
bundle first, and send Blades/default.log if a problem occurs.

See [playback details](VIDEO-PLAYBACK.md) and [validation](VALIDATION.md).
Historical 0.38 downloads remain in their versioned ZIP/commit; the obsolete
unversioned player pack and runtime Players directory are removed from latest.
