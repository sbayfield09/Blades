# Blades 0.28 native achievement Guide walkthrough

[Watch/download the MP4](../dist/Blades-v0.28-walkthrough.mp4)

Fresh 54-second 1280×720 desktop GPU capture at 30 fps, with 48 kHz stereo AAC
audio and the matching artwork pack. The visible label identifies simulated
profiles, achievements, storage and native Guide requests. The desktop capture
shows a request notice on A, not a recreation of the Guide. Native Guide
appearance, account authentication and console data require Xbox hardware.

- 00:00 Blade startup
- 00:02 Select Achievements signed out; request Guide sign-in
- 00:04 Simulated sign-in; resume the green browser with game-icon separators
- 00:06 Select a zero-unlock game, then return at 00:08
- 00:10 Enter the grid; navigate and page beyond 18 icons
- 00:15 A requests the selected achievement in the native Guide
- 00:17 Dismiss the desktop notice; same icon remains selected
- 00:20 A on the game strip requests that game's Guide achievements
- 00:23 Select another game and request its Guide view at 00:24
- 00:27 Select a game/app with no achievements; request its Guide view
- 00:32 Return to Games; Media/Music and System/Console Settings navigation
- 00:45 Confirm sign-out; account card clears at 00:47
- 00:49 Select Achievements signed out; cancel sign-in at 00:51

Achievement IDs and user/title targets are recorded in the capture event log.
Example game names, progress and pictures are confined to the preview tool and
tests. The native build reads local XAM data. The reference video is separate:
its green grid/game separators appear around 05:20–05:25, with native Guide
list/details around 04:30–04:45. See ACHIEVEMENTS.md for API verification.
